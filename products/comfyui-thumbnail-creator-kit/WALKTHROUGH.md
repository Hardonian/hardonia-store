# ComfyUI Thumbnail Creator Kit

Generate thumbnails fast — for videos, products, or social posts — entirely in ComfyUI.

## What's included
- The ComfyUI thumbnail workflow (nodes + graph)
- Supporting assets (templates, sample inputs)
- Setup walkthrough (README)
- Local validation steps

## Setup
1. Review README.md
2. Import the workflow into ComfyUI
3. Run local validation before sharing or deploying

## Use it for
- YouTube / video thumbnails
- Product thumbnails
- Social post visuals

Runs locally. No external API required for generation.
