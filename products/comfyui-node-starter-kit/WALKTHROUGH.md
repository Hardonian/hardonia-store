# ComfyUI Node Starter Kit

The fastest on-ramp to building your own ComfyUI pipelines.

## What's included
- A starter set of nodes and example graphs
- Supporting assets (node packs, sample graphs)
- Setup walkthrough (README)
- Local validation steps

## Setup
1. Review README.md
2. Import the example graphs into ComfyUI
3. Run local validation before extending

## Use it for
- Learning ComfyUI node patterns
- Bootstrapping custom workflows
- Reference graphs you can copy and modify

Runs locally. Learn the patterns, then build whatever you're shipping.
