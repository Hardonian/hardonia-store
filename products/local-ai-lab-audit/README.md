# Local AI Lab Audit — Buyer Pack

One-day audit of your private/local AI lab: ranked findings, repair plan,
and an APVA ROI estimate.

## Deliverables
- `README.md` — this file
- `LICENSE` — usage terms for the report
- `scripts/generate-local-ai-lab-audit.sh` — local lab snapshot generator
- `assets/report-template.md` — the report structure used for your audit

## What you get
1. A snapshot of your lab state (GPU, model endpoints, service health, disk).
2. A ranked findings list with owner, effort, and expected impact.
3. A repair plan and an APVA ROI estimate.
4. Optional: dashboard/monitoring setup on your machine.

## First step after purchase
1. Run `scripts/generate-local-ai-lab-audit.sh` on your lab machine
   (read-only; writes a report file only).
2. Send the output to your audit operator to seed the on-site pass.
3. Receive the ranked report + repair plan within the agreed window.
