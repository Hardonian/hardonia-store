# Audit Report Template

Below is the report structure delivered for the Local AI Lab Audit.

## 1. Lab inventory
Summarize hardware, OS, GPU cards, model endpoints, and key services found
during the on-site pass.

## 2. Bottlenecks (ranked)
1) Top bottleneck — GPU/VRAM, thermal, disk, or routing. Owner, evidence.
2) Second — ...
3) Third — ...

For each: observed behavior, measured evidence, and why it costs money/uptime.

## 3. Repair plan
| # | Finding | Fix | Owner | Effort | Expected ROI |
|---|---------|-----|-------|--------|-------------|
| 1 | ...     | ... | ...   | 2h     | 3x/etc      |

## 4. APVA ROI estimate
Estimate automated processing value added (APVA) — throughput per dollar and
time saved with the recommended fixes applied.

## 5. Dashboard / monitoring (optional)
Record the dashboard setup steps if purchased with the implementation day.
