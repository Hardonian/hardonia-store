# ComfyUI Workflow Subscription

**Price:** $29/mo

## What You Get
A local-first subscription delivering reusable ComfyUI workflow packs, templates, and runbooks you can run on your own GPU stack. New packs ship as they are built and verified on the lab's RTX 3060 / EPYC inference boxes.

## Who It's For
Local AI operators, homelab users, and solo founders running GPU stacks who want repeatable image pipelines without re-deriving them from scratch.

## The Pain It Solves
Scattered health checks, brittle automations, and undocumented workflows slow revenue work. This subscription turns that into a clean, versioned pack library.

## Included In The Bundle
- README (this file)
- WALKTHROUGH: how to import and run each workflow on your hardware
- SUPPORT: how to report issues and get fixes
- LICENSE: limited-use license terms
- MANIFEST.json: file inventory and version
- Emails: onboarding + value follow-ups
- posting-instructions.md: where to post / how to use

## Requirements
- ComfyUI running locally (or on your EPYC/RTX stack)
- SDXL-class checkpoint (8GB+ VRAM) for base workflows; Flux optional at 16GB+
- Models referenced per workflow are listed in each workflow's model manifest
