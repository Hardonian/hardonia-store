# ComfyUI Fashion Lookbook Kit

Fashion lookbook generation — outfit and style variations for catalogs and campaigns.

## What's included
- The ComfyUI fashion-lookbook workflow (nodes + graph)
- Supporting assets (style templates, sample inputs)
- Setup walkthrough (README)
- Local validation steps

## Setup
1. Review README.md
2. Import the workflow into ComfyUI
3. Run local validation before sharing or deploying

## Use it for
- Lookbook frames
- Style variations
- Campaign moodboards

Runs locally. Produce a cohesive set, then extend to your own styles.
