# Delivery Walkthrough

1. Confirm scope, repository, deployed URL, and approved test boundary.
2. Inventory stack, service ownership, tests, runtime configuration, and buyer-facing routes.
3. Reproduce only safe defects using non-destructive probes and isolated test data where required.
4. Deliver the evidence register and prioritized remediation plan.
5. Review findings together. Approve, defer, or reject fixes individually.

The audit is designed to reduce uncertainty. It does not promise that every issue can be fixed within a single sprint.
